# Dyson V8 Absolute 无线吸尘器使用说明书

## 产品简介

Dyson V8 Absolute 无线吸尘器采用戴森数码马达V8，转速高达每分钟107,000转，配合2 Tier Radial双层放射式气旋技术，可有效分离空气中细小的微尘和过敏原。

## 安全重要说明

### 使用前必读

- **请勿**在靠近水源或潮湿环境下使用
- **请勿**吸入正在燃烧或冒烟的物体，如烟蒂、火柴
- **请勿**用于吸取建筑粉尘或石膏粉末
- 充电时请使用**原装充电器**
- 若机器出现故障，请联系戴森客服，**请勿自行拆机**

### 电池安全

- 电池类型：锂离子电池
- 充电温度范围：5°C - 40°C
- 请勿将电池暴露于高温环境
- 长期不使用时，建议每3个月充电一次

## 安装指南

### 壁挂充电座安装

1. 选择靠近插座的墙壁位置
2. 使用附带的螺丝和膨胀管固定底座
3. 确保底座水平且稳固
4. 将充电线连接到充电座
5. 将吸尘器挂在充电座上即可开始充电

> **注意**：安装高度建议离地110cm，方便取放。

## 操作指南

### 基本使用

1. **安装吸头**：根据需要选择合适的吸头，对准接口推入听到"咔嗒"声
2. **开机**：扣动扳机即可启动，释放扳机即停止
3. **功率模式**：机身上设有两个功率档位
   - **普通模式**：适用于日常清洁，续航约40分钟
   - **MAX模式**：强力吸尘模式，续航约7分钟

### 清空集尘筒

1. 取下吸头
2. 将集尘筒对准垃圾桶
3. 向上拉动红色拉环，集尘筒底部自动打开
4. 灰尘落入垃圾桶后，将底部盖回，听到"咔嗒"声完成

### 清洗滤网

1. 取下顶部滤网盖
2. 取出滤网
3. 用**冷水**冲洗滤网（请勿使用热水或清洁剂）
4. 轻轻拍打去除多余水分
5. 自然晾干至少**24小时**后方可装回使用

> **重要**：滤网建议每月清洗一次，以保持最佳性能。

## 不同地面清洁指南

### 硬质地板（瓷砖、木地板）

- 推荐使用**软绒滚筒吸头**
- 使用普通功率模式即可
- 注意避开积水区域

### 地毯

- 推荐使用**直驱式吸头**
- 较厚地毯可使用MAX模式
- 定期清理吸头上的缠绕毛发

### 沙发和床垫

- 使用**迷你电动吸头**
- 可有效清除尘螨和皮屑
- 建议每两周深度清洁一次

## 故障排除

| 故障现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 不启动 | 电池耗尽 | 充满电后使用（约4-5小时） |
| 吸力减弱 | 滤网堵塞 | 清洗滤网并晾干 |
| 吸力减弱 | 集尘筒已满 | 清空集尘筒 |
| 运转时有异味 | 滤网长期未清洗 | 清洗滤网 |
| 充电指示灯不亮 | 充电器接触不良 | 检查充电器连接 |
| 运行中突然停止 | 气道堵塞 | 检查吸头、吸杆和进气口是否堵塞 |

## 常见问题

**Q: 可以用湿布擦拭机身吗？**
A: 可以，但请确保机身完全干燥后再充电。

**Q: 电池可以自行更换吗？**
A: 不建议自行更换，请联系戴森售后服务更换原装电池。

**Q: 能否吸取液体？**
A: 不可以，本产品为干式吸尘器，吸取液体会损坏马达。
