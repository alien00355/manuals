# 项目需求文档

## 项目名称

家庭说明书集合网页（Family Manuals）

## 项目目标

构建一个可线上访问的网页，集中管理家庭所有电器、家具等产品的说明书，支持分类浏览和全文搜索。

## 核心需求

| 编号 | 需求 | 优先级 | 状态 |
|------|------|--------|------|
| R1 | 收集并展示产品说明书（文字+图片） | P0 | ✅ 已完成 |
| R2 | 支持 PDF → Markdown → 网页的转换流程 | P0 | ✅ 已完成 |
| R3 | 按产品功能分类索引浏览 | P0 | ✅ 已完成 |
| R4 | 全文搜索，快速定位文字内容 | P0 | ✅ 已完成 |

| R6 | 每个产品页面醒目显示类型和品牌 | P0 | ✅ 已完成 |

## 用户画像

- 不懂代码的普通用户
- 拥有 Python 环境（用于 MinerU）
- 需要通过简单操作维护网站
- GitHub 账号：alien00355

## 非功能性需求

- 页面零外部运行时依赖（搜索为纯 JS，字体从 Google Fonts CDN 加载但非阻塞）
- 搜索响应时间 < 200ms
- 支持中英文内容
- GitHub Pages 免费托管
- 响应式断点：375px / 480px / 768px / 1024px
