# 设计规范

## 设计理念

**简洁直观，温暖亲切** — 像一个温馨的家庭档案柜，让查阅说明书成为轻松愉快的体验。

## 设计系统来源

通过 **ui-ux-pro-max** 设计数据库匹配推荐：
- **风格**：Bento Grids（Apple 式模块化卡片网格）
- **配色**：Book & Reading Tracker（书籍阅读追踪器暖色系）
- **字体**：Noto Sans SC（简体中文优化）

## 字体系统

- **主字体**：`"Noto Sans SC"` — Google Fonts 简体中文优化
  - 字重：300 (Light) / 400 (Regular) / 500 (Medium) / 600 (SemiBold) / 700 (Bold) / 800 (ExtraBold)
  - 加载方式：`<link>` + `preconnect`，非阻塞
- **回退字体栈**：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- **代码字体**：`"SF Mono", "Fira Code", "Consolas", monospace`
- **字号层级**：
  - 首页标题：2.3rem (800 字重)
  - 详情页标题：1.7rem (800 字重)
  - 章节标题 h2：1.2rem (700 字重)
  - 正文：1rem (400 字重，行高 1.75)
  - 辅助文字：0.8-0.93rem

## 组件规范

### 分类卡片（Bento Grid）
- 圆角 24px，白色背景，极浅阴影
- 悬停时上浮 6px + 缩放 1.02x + 光晕渐变出现 + 图标放大 1.18x
- 显示图标（Emoji）+ 分类名 + 数量徽章

### 产品卡片
- 圆角 18px，白色背景
- 顶部：类型标签（深琥珀→暖琥珀渐变） + 品牌标签（浅暖黄底）
- 悬停时上浮 4px + 缩放 1.01x

### 详情页布局
- 桌面端：左侧 225px 侧边栏（目录卡片） + 右侧主内容（大卡片 24px 圆角）
- 移动端：单栏，侧边栏折叠到顶部
- 顶部：醒目类型/品牌标签 + 产品标题（800 字重）
- 正文区域：最大宽度 72ch（最佳阅读体验）

### 导航栏
- 毛玻璃效果：`backdrop-filter: blur(18px)` + 半透明背景
- 粘性定位，64px 高度
- 搜索框 26px 胶囊圆角，聚焦时琥珀光晕

### 表格
- 圆角 10px，表头深棕渐变 + 白字
- 双层表头：主表头深色 / 子表头浅色
- 偶数行浅暖白斑马纹，悬停行高亮

### 图片
- 圆角 10px，浅边框，极浅阴影
- 最大高度 520px（桌面）/ 380px（平板）/ 280px（手机）
- 悬停缩放 1.015x，点击灯箱全屏放大

### 外部链接按钮
- 琥珀渐变 + 投影光晕，圆角 12px

## 间距系统

| 级别 | 值 | 用途 |
|------|-----|------|
| xs | 0.25rem (4px) | 微小间距 |
| sm | 0.5rem (8px) | 标签间距 |
| md | 1rem (16px) | 卡片内边距 |
| lg | 1.5rem (24px) | 区块间距 |
| xl | 2rem (32px) | 页面主间距 |

## 响应式断点

| 断点 | 宽度 | 适配 |
|------|------|------|
| 桌面 | ≥ 1025px | 两栏布局，完整侧边栏 |
| 小平板 | ≤ 1024px | 缩小内边距 |
| 平板 | ≤ 768px | 单栏布局，侧边栏内联 |
| 手机 | ≤ 480px | 紧凑导航，两列分类卡片 |

## 动效规范

- 过渡时长：200-350ms
- 缓动函数：`cubic-bezier(0.25, 0.1, 0, 1)`（自然减速）
- 悬停效果：上浮 2-6px + 阴影加深 + 可选缩放
- 尊重 `prefers-reduced-motion`：关闭所有动画
