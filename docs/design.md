# 🎨 设计规范

## 设计理念

**简洁直观，温暖亲切** — 像一个温馨的家庭档案柜，让查阅说明书成为轻松愉快的体验。

## 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色调 | `#E07B3C` | 暖橙色，用于按钮、标签、强调元素 |
| 主色深色 | `#C45C3A` | 陶土红，用于悬停态、链接 |
| 背景色 | `#FFF8F0` | 米白色，全局背景 |
| 卡片色 | `#FFFDF9` | 奶油色，卡片和内容区背景 |
| 文字色 | `#3D2C1E` | 深棕色，正文文字 |
| 次文字色 | `#7A6B5D` | 暖灰色，辅助文字 |
| 边框色 | `#E8DDD2` | 浅米色，分割线和边框 |
| 标签背景 | `#FDF0E4` | 浅暖橙，品牌标签背景 |
| 搜索高亮 | `#FFE0A3` | 暖黄色，搜索匹配高亮 |

## 字体系统

- **主字体**：系统原生字体栈
  - Windows: `"Microsoft YaHei"`, `"PingFang SC"`
  - Mac: `"PingFang SC"`, `"Hiragino Sans GB"`
  - 通用：`-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`
- **代码字体**：系统等宽字体（`pre`, `code`）
- **字号层级**：标题 1.75rem / 1.5rem / 1.3rem，正文 1rem（16px），辅助 0.85-0.9rem

## 组件规范

### 分类卡片
- 圆角 12px，白色背景，浅阴影
- 悬停时上浮 3px + 阴影加深
- 显示图标（Emoji）+ 分类名 + 数量

### 产品卡片
- 圆角 12px，白色背景
- 顶部：类型标签（暖橙底白字）+ 品牌标签（浅橙底）
- 标题 + 品牌名

### 详情页布局
- 桌面端：左侧 240px 侧边栏（目录） + 右侧主内容
- 移动端：单栏，目录折叠到顶部
- 顶部：醒目类型/品牌标签 + 产品标题

### 搜索框
- 圆角 24px 胶囊形
- 聚焦时暖橙色边框 + 光晕
- 下拉结果面板：白色背景 + 阴影

### 面包屑导航
- `首页 › 分类 › 产品标题`
- 当前页面加粗

## 间距系统

| 级别 | 值 | 用途 |
|------|-----|------|
| xs | 0.25rem (4px) | 微小间距 |
| sm | 0.5rem (8px) | 标签间距 |
| md | 1rem (16px) | 卡片内边距 |
| lg | 1.5rem (24px) | 区块间距 |
| xl | 2rem (32px) | 页面主间距 |

## 响应式断点

| 断点 | 宽度 | 适配 |
|------|------|------|
| 桌面 | ≥ 769px | 两栏布局，完整侧边栏 |
| 平板/手机 | ≤ 768px | 单栏布局，侧边栏内联 |
| 小手机 | ≤ 480px | 紧凑导航，两列分类卡片 |
